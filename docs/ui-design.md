# 觅途 Mitu 界面约定

## 品牌与视觉

- 用户确认名称为“觅途 Mitu”。产品定位为个人求职工作台，招聘投递仅支持 Boss，另提供笔试助手。
- 用户要求配色更加鲜艳。主色为蓝紫 `#5b4df5`，页面为浅蓝白，辅助色为淡紫、青蓝、珊瑚橙和琥珀色；深色模式采用深蓝背景与亮紫主色。主题颜色通过 `globals.css` 的语义变量统一，避免每页建立独立色系。
- Logo 和浏览器图标采用自有 SVG 路径标志，不需要外部图片或字体网络请求。
- 卡片使用实体背景、细边框和轻阴影；按钮与输入统一圆角。用间距、字号和分区表达层级。
- `front/server.config.js` 定义构建品牌参数，`front/lib/brand.ts` 为界面读取入口；包名和打包名称为 `mitu`。

## 页面结构

- 桌面为左侧固定导航、顶部路径和日期、主内容；移动端导航置顶并支持横向滚动，表单改为单列。
- 投递工作台将关键词、城市、职位类型和两项数量上限集中在搜索区；沟通内容可展开编辑，高级偏好默认折叠。右侧任务面板统一展示计划、准备检查、保存与启停操作，移动端按单列排列。
- 工作台右侧另设“静默投递”卡片，默认开启，提供独立模式保存和“查看浏览器/继续后台”入口；移动端随任务区域单列排列。模式不与原搜索配置混存，加载失败禁止保存默认值；未保存的模式草稿阻止新任务启动，启动、运行、停止和清理期间冻结修改。
- 窗口控制是异步意图：请求接收后显示“等待显示/等待进入后台”，以状态接口确认实际结果，不把请求成功描述成浏览器已经显示或最小化。查看和后台按钮不启动投递，仅控制本项目浏览器。
- 人工接管时任务面板显示“待人工处理”，保留停止入口；用户点击查看浏览器，完成登录或验证后再继续后台。静默说明保持“有界面浏览器在后台运行”的含义，不宣传完全无窗口、隐身或所有情形零闪现。
- 黑名单为独立页内标签，添加/删除立即生效，刷新只读取黑名单；岗位记录通过独立统计入口查看，不在工作台重复嵌入整页统计。
- JD 岗位库位于独立导航，分“岗位原文”和“需求总结”。筛选先应用，再供分页、多选范围、统计、分析和导出使用；完整原文、版本及搜索快照按需在详情展示。工作台只增加本次新增、版本更新、重复和失败四项采集计数。
- JD 本地关键词统计明确表示文字提及；AI报告单独展示自己的范围、分析覆盖、来源证据及过期提示。自动AI默认关闭，启用前提示发送JD到已配置服务；未配置或模块不可用时禁止启动。历史导入明确说明匹配未确认，排除和人工纳入不改投递记录。
- 摘要不复制固定招呼语，不把单次数量上限描述为每日剩余名额。职位类型使用单选下拉，始终且仅保留一个值；“不限”也是一个独立选项。
- 固定招呼编辑区允许较长内容（最多 2000 字），明确提示 Boss 首条招呼 100 字限制及超长文本会在进入聊天后按完整固定信息发送；同时提示需关闭 Boss 账号级自动招呼才能避免默认提示词先发送。
- 岗位统计按筛选、KPI、岗位记录、分布分析排列，9 张图表分成 3 组标签。筛选需点击应用，分页、刷新与 CSV 导出使用已应用条件；表格在自身容器内滚动，空数据提供说明。
- AI 和系统设置提供主表单、帮助栏及单一底部保存区，保留手动保存及 AI 模式开关的即时保存行为。保存结果在页内显示，加载失败时禁止保存空表单并提供重试。
- “笔试助手”作为独立导航入口，题目输入/图片识别与解析为主区，桌面运行状态、进程名称和捕获排除为侧区，移动端按单列排布。设置加载失败时不能保存或启动；运行中冻结设置，开始前要求保存草稿。
- 桌面或图片识别与网页草稿冲突时由用户选择是否替换，不自动覆盖；解析与题目对应，旧题解析不能作为当前题目发送。发送到桌面后收起网页解析，明确网页本身可被捕获；捕获排除以实际系统状态展示，不使用“监考不可见”等保证性文案。
- 系统设置仅保留 AI 服务地址、模型名称和访问密钥；机器人通知卡片、发送开关、Webhook 字段及说明已移除，保存区继续用于 AI 连接设置。
- 配置页显示未保存状态，刷新或关闭时提醒；站内切页不自动保存。任务运行、启动或停止中暂不可修改工作台配置。
- 深色模式沿用同一语义颜色体系；减少动画偏好通过 CSS 响应。
- 弹窗通过 `front/lib/use-modal-focus.ts` 统一管理焦点、键盘循环、Escape 关闭与滚动锁；关闭后返回触发按钮。菜单保留标签关联与键盘选择。

## 功能与验证边界

当前保留 AI 连接设置、数量上限、职位类型单选、登录状态、进度推送、黑名单、导出与配置保存行为。机器人通知配置已按用户要求停用；历史数据库行保留，配置接口不再读取或写入旧机器人键。数据库路径保持兼容。

静默投递已接入当前工作台。定时投递、账号注册和多人公网入口仍是方案，不在现有界面中标记为已上线；后续设计以 `docs/automation-multiuser-roadmap.md` 为准。

页面验证可以读取状态、打开菜单、切换分页或页内标签，避免真实投递、登出、保存修改后的配置和发送通知。前端生产构建后验证桌面、移动宽度和深色主题。

项目来源与上游许可保留在 README 和 LICENSE；独立视觉品牌不意味着重新授权上游代码。
