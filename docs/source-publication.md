# 源码发布说明

日期：2026-11-09

仓库：CloudskyRan/boss-auto-apply-assistant  
中文名称：Boss自动投简历助手  
本地产品品牌：觅途 Mitu，版本3.1.0。首次创建为私有仓库。

本次发布保留当前 Boss 业务、前端、桌面组件源码、构建脚本、锁文件和
技术文档。静默投递与JD功能已实现；定时、注册和多人服务仍为后续方案。

发布以审查后的当前源码建立独立初始历史，避免上传旧提交中的运行数据。
数据库、Cookie、浏览器资料、简历、密钥、备份、运行日志、编译产物和
内部协作记忆均不上传。无运行引用的旧截图、收款图片、浏览器扩展、Maven
本机设置及按端口强杀进程脚本不在发布范围，原本机文件保留。

发布配置取消固定的本机代理；使用者可在个人 Gradle 设置中配置代理。
首次构建与全新设备运行需要准备 Java21、Node.js、依赖和浏览器驱动。
当前完整空库初始化和干净环境端到端验收尚未完成；不提供个人数据库替代
正式初始化流程。GitHub源码仓库也不等于已上线可供多人使用的服务。
